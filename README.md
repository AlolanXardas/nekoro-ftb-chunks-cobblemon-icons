# Nekoro FTB Chunks - Cobblemon Icons

A small client-side mod that shows Pokémon from Cobblemon on the FTB Chunks minimap and large map with their own icons: shinies, regional and alternate forms, outlines for legendary, mythical, ultra beast and paradox Pokémon, and caught indicators. Made for my Nekoro Pokemon modpack.

Download: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/nekoro-ftbcci)

## Projects

- `minimap/` – NeoForge 1.21.1
- `minimap-fabric/` – Fabric 1.21.1

## Building

Needs JDK 21. Run `gradlew build` inside one of the project folders.
